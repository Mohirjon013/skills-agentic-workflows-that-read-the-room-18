## Recent updates

- **GitHub Agentic Workflows**: Automate repository tasks like triage, documentation updates, and CI investigation using Markdown workflow definitions compiled into GitHub Actions lock files (Source: [GitHub Blog](https://github.blog/latest/), [Awesome Copilot Workflows](https://awesome-copilot.github.com/workflows/)).
- **Copilot & GitHub Actions debugging**: Use Copilot on failing Actions runs to explain errors and propose fixes directly from workflow logs (Source: [GitHub Changelog](https://github.blog/changelog/)).
